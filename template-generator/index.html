Next Steps

  1. Make sure you're logged in to Wikimedia Commons
  2. Copy the template code and click "Create Template on Commons", pasting the code on the template-creation page
  3. Copy the category code and click "Create Category on Commons", pasting the code on the category-creation page
  4. The template and category will be ready to use on your WikiPortraits photos!
